# PixelPioneers Creative Library

A reusable production library for social content, brand graphics, short-form video, and client-ready creative packages.

**Principle:** Build once. Customize safely. Reuse consistently. Deliver professionally.

## Two operating modes
- **Studio mode:** create repeatable content for PixelPioneers Collective and approved house brands.
- **Client mode:** adapt approved templates into scoped, branded deliverables for paying clients.

## Library map
- `templates/` — editable layout and copy systems
- `graphics/` — brand kits, social graphics, thumbnails, and export presets
- `video/` — scripts, storyboards, shot lists, motion systems, and editing presets
- `brand-kits/` — brand-specific tokens, voice, and usage rules
- `client-packages/` — productized service tiers and delivery checklists
- `workflows/` — intake, production, QA, publishing, and archive procedures
- `catalog/` — asset register and reuse metadata

## Asset status
The initial commit establishes the structure and production specifications. Add binary source files (for example, Canva exports, SVG/PNG files, project files, MP4s) to the matching folders as they are created. Do not mark a visual or video asset as available until its actual file is committed.

## Naming convention
`brand_channel_format_topic_version_YYYYMMDD.ext`

Example: `stillbecoming_instagram_quote_discipline_v01_20261106.png`

## Required metadata for every reusable asset
- Asset ID and title
- Brand / client applicability
- Format and dimensions or duration
- Editable source location
- Export location
- License / rights status
- Version, owner, and last-reviewed date
- Usage notes and CTA

## Quality and rights rules
1. Use original, licensed, or client-provided assets only.
2. Keep editable source files alongside final exports whenever possible.
3. Never reuse a client's confidential content or identity without written permission.
4. Check spelling, safe areas, aspect ratio, audio rights, captions, and brand consistency before delivery.
5. Keep client-specific work separated from public reusable templates.
