# Reusable Social Template Specifications

Create each layout as an editable master, then export platform-specific copies.

## 1. Quote / affirmation card
- Primary sizes: 1080×1350 (feed), 1080×1920 (story).
- Layout: strong headline, short supporting line, restrained brand signature, optional CTA.
- Keep text inside a generous safe area; avoid placing key text at the extreme edges.
- Variants: photography background, solid background, minimal typography.
- Fields to customize: quote, author/attribution, brand, accent, CTA.
- Export: PNG or JPG; retain editable source.

## 2. Educational carousel
- Size: 1080×1350 per slide.
- Sequence: hook → problem → 3–5 teaching points → example → action → CTA.
- Use one idea per slide, consistent numbering, readable contrast, and a clear closing slide.
- Export each slide individually and as a combined PDF where useful.

## 3. Promotional / launch post
- Sizes: 1080×1080 and 1080×1350.
- Sequence: offer or announcement → value proposition → proof or detail → CTA.
- Required checks: accurate offer details, dates, URL, and terms.

## 4. Story / vertical announcement
- Size: 1080×1920.
- Structure: top context, central message or visual, bottom CTA.
- Leave room for platform interface overlays.

## 5. Thumbnail / cover
- Sizes: create a master at 1920×1080 for 16:9 and 1080×1920 for vertical covers.
- Use one clear subject, short title, strong hierarchy, and consistent series marker.

## Design tokens
Define per brand rather than hard-coding colors:
- Primary / secondary / accent colors
- Heading and body typefaces
- Logo clear space and minimum size
- Photography and illustration direction
- Corner, border, and shadow treatment
- Voice and CTA style

## Template acceptance checklist
- Editable master exists.
- Placeholder text is clearly labeled.
- Font and image licensing is documented.
- Contrast and mobile readability checked.
- Correct exports and preview images are present.
- No client-specific data remains in the master.
