# Graphics Production Guide

## Reusable graphic families
1. Brand identity: logo lockups, profile images, cover/banner systems.
2. Social content: quote cards, carousels, announcements, testimonials, event posts.
3. Video support: thumbnails, title cards, lower thirds, end screens, subtitles.
4. Marketing: lead magnets, product covers, offer sheets, presentation slides.

## Source and export structure
For each asset family, store:
- `source/` — editable originals (SVG, design files, layered files).
- `exports/` — approved PNG/JPG/PDF output.
- `previews/` — lightweight preview images.
- `README.md` — dimensions, fonts, color tokens, and customization instructions.

## Production rules
- Use vector formats for logos where possible.
- Keep text, background, and imagery on separate editable layers.
- Use licensed fonts and imagery; record source and license.
- Export at the target platform's required dimensions.
- Verify legibility at phone size and check contrast.
- Include transparent-background logo exports when appropriate.

## Brand adaptation
Replace only approved brand tokens and copy fields. Do not stretch logos, recolor protected marks, or change client claims without approval.
